# 文章内の文字種混入チェッカー

複数のテキストファイルを読み取り、通常のMarkdownコードフェンスを除外した本文から、ハングル・アラビア文字・英字系の文字を検出する。

Python 3.11以降が必要。外部パッケージのインストールは不要。

## 実行方法

```bash
# 通常の使い方 (1ファイル)
$ python check_text.py draft.md
# 複数ファイル入力
$ python check_text.py draft.md notes.txt reply.md
# json形式で出力
$ python check_text.py --format json draft.md notes.txt
# 入力ファイルのエンコード指定 (デフォルトはUTF-8)
$ python check_text.py --encoding cp932 old_text.txt
```

入力ファイルは変更しない。相対パスの基準は実行時のカレントディレクトリ。ファイルは指定順に処理し、同じ絶対パスへ解決される指定は最初の1回のみ処理する。出力のパス表記は最初の指定を保つ。

ディレクトリや通常のファイルではないパスはエラー。再帰探索と独自のワイルドカード展開は行わない。シェルが展開した複数パスは受け取れる。

ファイル名がハイフンで始まる場合は、引数の区切りを使う。

```bash
$ python check_text_scripts.py -- "-draft.md"
```

## 文字種の切り替え

既定では3分類すべて有効。

| 分類             | 有効化   | 無効化      |
| ---------------- | -------- | ----------- |
| 英字系           | --latin  | --no-latin  |
| ハングル         | --hangul | --no-hangul |
| アラビア文字範囲 | --arabic | --no-arabic |

```bash
$ python check_text_scripts.py --no-latin draft.md notes.txt
$ python check_text_scripts.py --no-hangul --no-arabic draft.md
```

同じ分類の有効化・無効化を複数回指定した場合は、最後の指定が有効。
3分類をすべて無効にした場合も、読み取りと未閉鎖フェンスの確認は行う。

## 検出対象

| 分類ID | 対象                                                        |
| ------ | ----------------------------------------------------------- |
| LATIN  | ASCII英字、全角英字、下表の一般的なアクセント付きラテン文字 |
| HANGUL | 音節、字母、互換字母、拡張字母、半角ハングル、声調記号      |
| ARABIC | アラビア文字の基本・補助・拡張ブロック、表示形、数式用文字  |

| 分類   | 対象コードポイント                                                                                         |
| ------ | ---------------------------------------------------------------------------------------------------------- |
| LATIN  | U+0041–005A、U+0061–007A、U+00C0–00D6、U+00D8–00F6、U+00F8–024F、U+1E00–1EFF、U+FF21–FF3A、U+FF41–FF5A     |
| HANGUL | U+1100–11FF、U+302E–302F、U+3130–318F、U+A960–A97F、U+AC00–D7AF、U+D7B0–D7FF、U+FFA0–FFDC                  |
| ARABIC | U+0600–06FF、U+0750–077F、U+0870–089F、U+08A0–08FF、U+FB50–FDFF、U+FE70–FEFE、U+10EC0–10EFF、U+1EE00–1EEFF |

対象範囲に一致する文字が1文字でもあれば検出する。言語判定や正誤の判定は行わない。日本語の途中にある英字、固有名詞、URLなども検出対象となる。

同じ分類が連続する部分を1件とする。
hello world は2件、abc한글はLATINとHANGULの2件。

アラビア文字範囲内の専用数字・句読点・記号・結合記号も検出する。ペルシャ語などで使われる同じ系統の文字も含む。数字0–9、全角数字、乗算記号、除算記号、U+FEFFは対象外。

文字列は正規化しない。結合アクセント単独はLATINに含めず、英字に結合アクセントが付いた場合は英字自体を検出する。丸囲みや数式用などの装飾ラテン文字を含め、すべてのラテン系表現を網羅するものではない。固定範囲内の未割当コードポイントも一致し得る。

## コードブロック

拡張子にかかわらず、次のフェンス形式を除外する。

- バッククォート U+0060 またはチルダ U+007E の同一文字が3個以上連続する開始行。
- フェンス前の半角スペースは0〜3個。
- 開始行の言語指定なども、その行全体とともに除外。
- バッククォートの情報文字列にバッククォートが含まれる場合は、開始行として扱わない。
- 終了行は、開始と同じ記号が開始時以上の個数連続し、後ろには半角スペース・タブだけが続く行。
- 異なる記号、短いフェンス、末尾に他の文字がある行では閉じない。

開始行・内容・終了行はすべて除外する。

未閉鎖のままEOFに到達した場合は、開始行から末尾までを除外したうえで、開始行番号付きのエラーを報告し、終了コード2を返す。そのファイルでフェンスより前に検出した結果は保持し、他のファイルの処理も続ける。

初回の対応範囲は通常のフェンス形式のみ。インラインコード、インデント形式のコード、引用やリストの構造に応じたネスト処理、HTMLブロックの除外は行わず、通常本文と同じくチェックする。完全なMarkdownパーサーではない。

## 文字コードと位置

- 入力の既定値は utf-8-sig。UTF-8のBOMあり・なしに対応する。
- --encoding で入力文字コードを指定できる。
  自動推定や不正バイトの置換は行わない。
- 出力はUTF-8。入力にcp932などを指定しても出力の文字コードは変わらない。
- LF・CRLF・CRに対応する。垂直タブなどは改行として扱わない。
- 行・列は1始まり。列はUnicodeコードポイント数で数え、タブは1文字とする。
- 列はバイト数や画面上の表示幅とは異なる。結合文字や複数コードポイントの絵文字は、その構成文字数だけ数える。
- 既定の文字コードで除去した先頭BOMは列数に含めない。

## 出力と終了コード

通常の出力例：

```text
draft.md:12:8: [LATIN] "hello"
draft.md:18:3: [HANGUL] "한글"
OK: notes.txt
集計: 確認成功2ファイル / 検出2件 / エラー0ファイル
```

通常の結果と集計は標準出力、エラーは標準エラー出力に出す。

--format json
では標準出力を1個のJSONオブジェクトにする。ファイル単位のエラーもJSON内に格納する。

```bash
$ python check_text_scripts.py --format json draft.md notes.txt > results.json
```

| 要素             | 内容                                               |
| ---------------- | -------------------------------------------------- |
| files            | ファイルごとの結果。指定順、重複除外後             |
| files[].path     | 入力時のパス表記                                   |
| files[].status   | clean / found / error                              |
| files[].findings | line、column、script、textを持つ検出一覧           |
| files[].error    | 正常時はnull、エラー時は説明文字列                 |
| summary.checked  | エラーなく確認を完了したファイル数                 |
| summary.clean    | statusがcleanの数                                  |
| summary.flagged  | statusがfoundの数                                  |
| summary.failed   | statusがerrorの数                                  |
| summary.matches  | 全ファイルの検出件数。未閉鎖フェンス前の検出も含む |
| exit_code        | コマンド全体の終了コード                           |

checked = clean + flagged。
未閉鎖フェンスのあるファイルはfailedに数え、flaggedには数えないが、検出結果自体はfindingsとmatchesに残す。

| 終了コード | 意味                                                       |
| ---------- | ---------------------------------------------------------- |
| 0          | 全ファイルの確認に成功し、検出なし                         |
| 1          | 全ファイルの確認に成功し、1件以上の検出あり                |
| 2          | 引数・設定不正、読み取り失敗、未閉鎖フェンスのいずれかあり |

読み取りに失敗したファイルの部分的な検出結果は採用しない。空ファイルはclean。ファイル別のエラーがあっても他のファイルの処理は続ける。

引数不正や未知の文字コード名は、JSON指定時もargparseの通常のエラーメッセージを標準エラー出力へ出し、終了コード2で終了する。

終了コード1は「対象文字が見つかった」という意味。呼び出すAIやプログラムは、終了コード1をスクリプト自体の実行失敗と区別して扱う。
