# spark-coding-agent

Gemini タスク (旧 Spark) に python か nodejs でコーディングをさせるスキル
(実験中)

## 使い方

1. プロジェクトを zip か tar(.gz, .xz) にまとめる
  (このとき環境のパッケージ(`.venv` や `node_modules`) は **消さない** )

2. 必要であればプロジェクトで使用するランタイムもまとめておく

    - 現時点(2026/10/28)では環境の `nodejs` が古い (v18系) ため
      添付しておくか　Google ドライブに置いて参照させることを推奨します

3. タスクモードにして先程のファイルをアップロード

4. `@spark-coding-agent` とともに依頼する作業を伝える

    - コーディングエージェント/ハーネスに
      `/goal` を投げる感覚でプロンプトを組むと効果的です

完了後は成果物の差分パッチ (.patch)
か成果物をzip/tar圧縮したものがダウンロードできます

## 注意点

- タスク (Spark) 内の環境からは直接インターネットに接続できません
  - 検索ツール等で調べたりすることは可能
  - (インターネットにアクセスできるほうの) ブラウザツールからは VM 内の
    localhost 内にアクセスできません (おそらく別環境)
    - ヘッドレスな chromium は存在するのでそちらを触らせてください

- タスクは1件ごとに消費量がカウントされます (カウント量自体は謎)
  - まとめてやってもらった方が多分お得になります (未検証)
