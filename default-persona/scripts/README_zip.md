# zip.py ― Info-ZIP形式の実用互換CLI

Python標準ライブラリの zipfile を使い、
よく使う zip コマンドの引数で操作できる単一ファイルのCLIです。
外部の zip / unzip、追加のpipパッケージは実行時に使用しません。

**Info-ZIP 3.0の完全互換品ではありません。**
以下の対応範囲で、コマンドの先頭を置き換えて使用できます。
未対応オプションは終了コード16で拒否します。

## 動作環境

- CPython 3.11以降を想定。Linuxを主対象とします。
- 標準ライブラリのみ。通常の圧縮にはzlib、bzip2にはbz2が必要です。
- Python 3.11.2を対象に設計しました。
- 今回の実行検証環境は Linux / CPython 3.12.14 /
  Info-ZIP 3.0 / UnZip 6.00です。
  Python 3.11での実行検証は行っていません。
- 既存項目を再圧縮せず保持する部分にCPythonのzipfileの内部属性を使います。
  将来のPythonバージョンでは同梱テストによる確認が必要です。

## 最初の使い方

圧縮したいファイルのあるディレクトリをカレントにして実行してください。

```sh
# 元のコマンド
zip -r9 backup.zip project/ -x '*.tmp' '*/__pycache__/*'

# 先頭を置き換える
python /path/to/zip.py -r9 backup.zip project/ -x '*.tmp' '*/__pycache__/*'
```

アーカイブ名に拡張子がない場合は .zip を補います。
a.tar のように既に拡張子がある場合は、そのままの名前を使用します。

## 使用例

```sh
# 作成・追加・同名項目の置換
python zip.py archive.zip report.txt photo.png

# 再帰圧縮、静かな実行、圧縮レベル9
python zip.py -rq9 archive.zip folder/

# 新しいファイルと、既存項目より更新日時が新しいファイルだけを追加・更新
python zip.py -ru archive.zip folder/

# 既存項目のみ更新。新しい項目は追加しない
python zip.py -rf archive.zip folder/

# ZIP内の名前を指定して削除
python zip.py -d archive.zip '*.tmp' 'folder/cache/*'

# 対象を限定して別のZIPにコピー
python zip.py -U archive.zip '*.txt' --out texts.zip

# ディレクトリ構造を外して格納
python zip.py -rj images.zip images/

# 再帰探索し、.pyだけを格納
python zip.py -r source.zip . -i '*.py'
python zip.py -R source.zip '*.py'

# ファイル一覧を標準入力から取得（1行につき1パス）
find folder -type f | python zip.py -@ archive.zip

# 標準入力のデータを、名前「-」の項目として格納
printf 'hello\n' | python zip.py archive.zip -

# ZIPのバイト列を標準出力へ
python zip.py -rq - folder/ > archive.zip

# 作成後のCRC検証。不足ファイルがあれば変更を取り消す
python zip.py -rT -MM archive.zip folder/

# パスワード等の追加オプションは使えないためヘルプで確認
python zip.py --help
```

シェルのワイルドカード展開を避ける必要があるパターンは引用符で囲んでください。出力先が標準出力の場合、進捗メッセージは標準エラーに出力します。

## 対応オプション

| 引数                                      | 動作                                                       |
| ----------------------------------------- | ---------------------------------------------------------- |
| 指定なし                                  | 新規作成、追加、同名項目の置換                             |
| -r / --recurse-paths                      | 指定したディレクトリを再帰探索                             |
| -R / --recurse-patterns                   | カレント以下を再帰探索し、指定パターンで選択               |
| -u / --update                             | 新規項目を追加。既存項目は日時が新しい場合のみ更新         |
| -f / --freshen                            | 既存項目だけを日時に基づいて更新                           |
| -d / --delete                             | ZIP内の名前・パターンで項目を削除                          |
| -U / --copy / --copy-entries              | ZIP内の項目を選択し、--out にコピー                        |
| -O FILE / --out FILE / --output-file FILE | 入力を保持し、別のZIPに結果を出力                          |
| -j / --junk-paths                         | ディレクトリ名を除去。衝突する同名ファイルはエラー         |
| -p / --paths                              | パスを格納する指定に戻す                                   |
| -D / --no-dir-entries                     | ディレクトリ自体の項目を省略                               |
| -y / --symlinks                           | リンク先文字列とUnix属性を格納                             |
| -0 ～ -9                                  | 無圧縮、またはdeflate圧縮レベル。既定値6                   |
| -Z METHOD / --compression-method METHOD   | store / deflate / bzip2                                    |
| -n SUFFIXES / --suffixes SUFFIXES         | .zip:.gz のように無圧縮にする接尾辞を指定                  |
| -i PATTERNS / --include PATTERNS          | 格納名に対する採用パターン                                 |
| -x PATTERNS / --exclude PATTERNS          | 格納名に対する除外パターン                                 |
| -@ / --names-stdin                        | 標準入力からパス一覧を取得                                 |
| -nw / --no-wild                           | ワイルドカードを無効化                                     |
| -ws / --wild-stop-dirs                    | * と ? が / を越えない。** は越える                        |
| -t DATE / --from-date DATE                | 指定日以降。YYYY-MM-DD または MMDDYYYY                     |
| -tt DATE / --before-date DATE             | 指定日より前                                               |
| -T / --test                               | 確定前にzipfileでCRC検証。既存ZIP単独の検証も可能          |
| -MM / --must-match                        | 入力の未一致・読み取り不可をエラーにし、確定前なら取り消し |
| -m / --move                               | CRC検証・保存成功後、今回格納した元ファイルを削除          |
| -X / --strip-extra                        | 新規・置換項目の任意のUnix拡張情報を省略                   |
| -o / --latest-time                        | ZIPの更新日時を最新項目の日時に設定                        |
| -b DIR / --temp-path DIR / --temp-dir DIR | 一時ファイル作成ディレクトリ                               |
| -z / --archive-comment                    | 標準入力からZIPコメントを取得                              |
| -c / --entry-comments                     | 追加・置換項目の1行コメントを取得                          |
| -sf / --show-files                        | 操作対象名を出力して終了。ZIPは変更しない                  |
| -q / --quiet                              | 進捗を抑制。警告・エラーは残す                             |
| -v / --verbose                            | サイズ・CRCを追加表示。引数がこれだけならバージョン        |
| -h / -h2 / -H / -? / --help / --more-help | ヘルプ                                                     |
| --version                                 | バージョン                                                 |
| --                                        | 以降をオプションとして解釈しない                           |

- -rq9 などの短縮オプション連結、-Zdeflate、
  -Z=deflate、--out=name.zip を受け付けます。
- オプションはファイル名の後ろにも置けます。
- -i / -x のリストは、次のオプション・単独の @・引数末尾で終了します。
- -i @include.txt、-x @exclude.txt は
  UTF-8のパターン一覧を読み込みます。1行につき1パターンです。
- ZIPOPT 環境変数があれば既定引数として読み込みます。
  未設定の場合は ZIP を読み込みます。
- 日付・ZIP内のDOS日時は実行マシンのローカルタイムを使用します。
- -r では隠しファイルも探索します。

## 既存ZIPの更新と失敗時の動作

同名項目は置換し、重複エントリを作りません。変更しない項目は圧縮済みデータをそのままコピーするため、再圧縮しません。既存のアーカイブコメント・項目コメントも保持します。

出力は一時ファイルに作成し、必要な検証後に os.replace で置き換えます。
読み書きの途中で致命的なエラーが発生した場合、確定前の元ZIPを保持します。--out の既存出力も同様です。
一時ディレクトリが別ファイルシステムでも、最終置換は出力先のファイルシステム上で行います。

-MM がない場合、見つからないパスは警告にして、ほかの入力を続けます。
読み取りできないファイルは警告にしてスキップし、既存項目の置換に失敗した場合は元項目を保持します。
読み取り失敗があった場合は終了コード18です。書き込み開始後のI/Oエラーでは、その操作全体を確定しません。

-m は一時ZIPのCRC検証を必ず実行し、保存後に元ファイルの識別情報・サイズ・変更時刻等を再確認してから削除します。
読み取りエラーがあった実行では元ファイルを削除しません。ディレクトリは今回選択され、かつ空になったものだけ削除します。

## 完全互換ではない点

| 項目                                | この実装の範囲                                                          |
| ----------------------------------- | ----------------------------------------------------------------------- |
| 暗号化作成 -e / -P                  | 未対応。標準zipfileには暗号化ZIPを作成する機能がない                    |
| 既存の暗号化項目                    | 変更せずに保持・削除・コピー可能。新規項目は暗号化されない              |
| 暗号化ZIPでの -T / -m               | パスワード受付を実装していないため検証不可。エラーにして保存を中止      |
| 分割ZIP -s など                     | 作成・編集とも未対応                                                    |
| 修復 -F / -FF、自己展開調整 -A / -J | 未対応                                                                  |
| 同期 -FS、差分 -DF、追記最適化 -g   | 未対応                                                                  |
| 改行変換 -l / -ll、FIFO -FI         | 未対応                                                                  |
| 表示・ログの細かなオプション        | 一覧にないものは未対応                                                  |
| 長いオプション名の省略、否定形      | 未対応。正確なオプション名が必要                                        |
| -X                                  | コピーされる既存項目の拡張情報は保持。新規・置換項目だけに適用          |
| -sf                                 | 実装した操作で実際に変更・コピー・削除する対象名を表示                  |
| -D と -m の組み合わせ               | 格納したファイルだけ削除。省略したディレクトリは残る                    |
| 圧縮サイズ・ZIPバイト列             | 圧縮の自動的なstore切り替え、内部ヘッダー、拡張情報などが異なる         |
| 出力メッセージ                      | 進捗・ヘルプの文章や表示形式は一致しない                                |
| 終了コード                          | 主要コードを合わせるが、細かなエラー分類は完全一致しない                |
| stdout出力                          | ZIP全体を一時ファイルに作成してから送信。逐次配信ではない               |
| ZIP64                               | zipfileの自動ZIP64に対応。実容量4 GiB超の検証は未実施                   |
| 日時                                | DOS日時は2秒単位。1980～2107年の範囲に丸める                            |
| 文字コード                          | 新規項目はzipfileのASCII/UTF-8方式。任意のロケール変換指定は未対応      |
| 対象OS                              | Linux中心。Windows固有属性、macOSリソースフォーク、ACL、xattr等は未対応 |
| 元ZIPの重複名                       | 安全な置換規則を定められないためエラーにして編集を拒否                  |

標準zipfileの制限は、追加パッケージやZIP形式の低レベル実装で拡張する余地があります。このスクリプトでは明示した範囲だけを実装しています。

## 終了コード

| コード | 意味                                               |
| ------ | -------------------------------------------------- |
| 0      | 成功                                               |
| 3      | 壊れたZIP、重複項目等、編集できないアーカイブ      |
| 8      | CRC検証失敗                                        |
| 9      | 必要な既存ZIPがない、または割り込み                |
| 12     | 対象がない、または更新対象がない                   |
| 14     | 標準出力のパイプ切断                               |
| 15     | ファイルシステム・出力I/Oエラー                    |
| 16     | 未対応オプション、無効な指定、利用できない機能     |
| 18     | 読み取り失敗、-MM の未一致、処理中のファイル変更等 |

## テスト

```sh
python test_zip.py -v
```

標準ライブラリのunittestで実行できます。
比較テストは実行環境に zip / unzip がある場合にだけ実行します。
これらは zip.py 自体の実行時依存ではありません。

再帰圧縮、更新・削除、名前・内容のInfo-ZIP比較、日本語名、CP437名、シンボリックリンク、暗号化済み項目の保持、データディスクリプタ、ZIP64ローカルヘッダー、SFX接頭部、標準入出力、未対応引数の拒否、途中失敗時の元ZIP保持を検証します。
