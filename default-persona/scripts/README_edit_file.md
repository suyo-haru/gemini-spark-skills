# 部分編集ツール

`edit_file.py`
は、検索文字列がちょうど1箇所に完全一致した場合だけ置換するPythonスクリプトです。Python
3.10以上で動作し、追加ライブラリは不要です。

## 引数で1箇所を置換

```powershell
python edit_file.py target.md --search "長袖のTシャツ" --replace "長袖のカットソー"
```

`--replace ""` で削除できます。検索文字列が `-` で始まる場合は
`--search="-元の文字列"` と指定します。

## ファイルから複数箇所を置換

次の内容をUTF-8で `edits.txt`
に保存します。マーカー行に字下げや余分な空白を付けず、Markdownのコードフェンスはファイルに含めないでください。

```text
<<<<<<< SEARCH
私は長袖のTシャツ一枚になった腕をさすりながら、
=======
私は長袖のカットソー一枚になった腕をさすりながら、
>>>>>>> REPLACE

<<<<<<< SEARCH
変更前の別の文章
=======
変更後の別の文章
>>>>>>> REPLACE
```

```powershell
python edit_file.py target.md --blocks edits.txt
```

標準入力の場合は `python edit_file.py target.md --blocks -`
にUTF-8のブロックを渡します。

確認だけ行う場合は、どちらの形式でも `--dry-run` を追加します。

## 一致と保存のルール

- 部分一致・曖昧一致・正規表現は使いません。字下げや空白も検索文字列に含みます。
- 一致なし、複数一致、空の検索文字列、ブロックの構文不正はエラーです。
  `aaa` に対する `aa` のような重なった一致も複数一致として拒否します。
- ブロックは上から順に、直前の置換を反映した内容に適用します。後続の検索文字列はその時点で1箇所に一致する必要があります。
- 全ブロックの検証が成功してから、同じフォルダの一時ファイルを経由して保存します。途中のブロックが失敗しても、対象ファイルは変更しません。
- UTF-8専用です。UTF-8 BOMの有無、編集対象外の内容、
  末尾改行を維持します。別の文字コードは事前に変換してください。
- ブロック本文の直後から終了マーカーまでの改行1個は区切りとして扱い、検索・置換文字列には含めません。
  文字列自体を改行で終えるには、マーカーの直前に空行を1行追加します。
  空の置換は `=======` の次の行にそのまま `>>>>>>> REPLACE` を置きます。
- 対象ファイルがCRLFで統一されている場合、ブロック本文の改行もCRLFにそろえます。
  LFや混在改行のファイルではブロック本文の改行をそのまま使います。引数形式は改行も完全一致です。
- マーカーそのものと完全に同じ行を本文に含めるエスケープ形式はありません。その場合は引数形式を使ってください。
- 保存直前に元データとの比較を行います。ただし比較後から保存までの同時更新を完全には防げないため、同じファイルを別の処理から同時に編集しないでください。
- シンボリックリンクを指定すると、そのリンク先ファイルを編集します。保存時にはファイルを置き換えるため、ハードリンクとの共有や所有者・ACLなど全メタデータの保持は保証しません。

成功時は終了コード `0`、適用・入出力エラーは `1`、
引数の使い方の誤りは `2` を返します。
