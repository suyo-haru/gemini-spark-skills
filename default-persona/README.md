# default-persona

## これ何？

基本ツール・環境説明と、基本性格を書いた個人用のスキル。
スキル本体は人間によって手書きで書かれたスキルなのであまり期待しないこと。

## 付属スクリプト

### `scripts/zip.py`

環境にない `zip` コマンドの代替スクリプト。
詳しくは [README](./scripts/README_zip.md) を参照。

### `scripts/edit_file.py`

テキストファイルの置換編集用スクリプト。
詳しくは [README](./scripts/README_edit_file.md) を参照。
